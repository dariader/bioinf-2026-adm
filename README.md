# Статистика приёма 2026/27 — GitHub Pages dashboard

Статический интерактивный dashboard для данных приёмной кампании Института биоинформатики.

## Состав

- `index.html` — страница dashboard;
- `styles.css` — оформление;
- `app.js` — загрузка JSON и интерактивные графики;
- `data/admissions.json` — агрегированные данные без `platform_id`.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`.
6. Через несколько минут dashboard станет доступен по адресу GitHub Pages.

Важно: если открыть `index.html` напрямую как локальный файл (`file://`), браузер может запретить `fetch()` JSON. Для локальной проверки запустите простой HTTP-сервер, например `python -m http.server 8000`, и откройте `http://localhost:8000`.

## Фирменный стиль

Использована палитра из публичной страницы фирменного стиля Института биоинформатики:

- голубой `#3A81E8`
- тёмно-синий `#2D528A`
- серый `#3C3C50`
- белый `#FFFFFF`
- дымчато-белый `#F5F5F5`

Типографика: Open Sans с системным fallback.

Источники фирменного стиля:

## Приватность

В опубликованном JSON нет `platform_id` и других прямых идентификаторов. Dashboard использует агрегированные распределения. Редкие города и редкие категории в демографических срезах объединяются в «Другие».

## Особенности исходного файла

В исходной книге 301 строка анкет и 299 уникальных `platform_id`; часть этапов содержит записи, которых нет в листе «Анкеты». Поэтому общая воронка показывает уникальные значения по соответствующим листам, а демографические срезы строятся только по сопоставленным анкетам.
